# Código interactivo

## Código con pestaña "Fire it up!"

Si tu curso usa Dart/Flutter, puedes asociar un bloque de código a un Gist de DartPad con `trycode=<gistId>` en el mismo renglón del fence. Reemplaza `REPLACE_WITH_GIST_ID` por el ID real de tu Gist.

```dart trycode=REPLACE_WITH_GIST_ID
void main() {
  print('Hola, mundo!');
}
```

## DartPad independiente

```dartpad
REPLACE_WITH_GIST_ID
```
