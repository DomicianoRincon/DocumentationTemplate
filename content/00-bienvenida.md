# Bienvenida al curso

Esta es una lección de ejemplo que viene con el template. Puedes borrarla y reemplazarla por tus propias lecciones — sirve para mostrar la sintaxis Markdown soportada y como referencia rápida mientras escribes contenido nuevo.

Un párrafo normal soporta `código inline`, **negrita**, *cursiva* y [enlaces con el estilo del curso](https://example.com). Todo eso es Markdown estándar — cualquier editor con vista previa de Markdown te muestra esto correctamente.

## Una subsección

Los `##` se agregan automáticamente a la tabla de contenido de la derecha.
